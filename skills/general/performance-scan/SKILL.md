# performance-scan

找出真实热路径上的性能问题：N+1、串行 I/O、循环内重复计算、O(n²)、同步阻塞、无界内存、列表渲染与冷启动。只报能说清入口调用链、用户数据规模或调用频率、以及明确代价的发现。

在当前 harness 里由代理直接按本指引处理：用本环境已有的读代码、搜索、git 与检查工具查看仓库并整理结果。不要另起扫描启动器、命令行入口、批处理运行框架，也不要把通读交给外部 CLI 后端。

默认**只读**：只出带证据的中文报告，不创建 issue，不改被扫仓库，不提交，不联网发布。写入 Fast Ship 必须由本轮用户明确授权，规则见 [建单](references/filing.md)，执行时走 `$fast-ship`。

## 1. 范围与证据基线

扫描对象以本轮用户指定的仓库、路径或方向为准；未指定则用当前工作区。本技能没有默认仓库清单，也不要求一次扫完多个互不相关的仓库——用户点了几个就看几个。

开始时记下仓库标识（如 `owner/name` 或本地显示名）和当时的 HEAD **SHA**。之后每条发现的文件路径与行号都以该 SHA 为准。需要对照历史版本时，用 git 在该 SHA 上读文件，不要凭记忆里的旧路径下结论。

完成：范围和证据 SHA 已明确；建单默认关闭，除非用户在本轮明确授权。

## 2. 探索

按 [扫描准则](references/criteria.md) 探索。用户已指定方向就沿该方向；否则从入口（请求 handler、路由、应用启动、列表/渲染）沿调用链查看热路径，再按准则里的问题类型搜线索。

查证时直接使用 harness 里的常规手段，例如读源码、搜索引用、`git log` / `git show`，以及**当前环境里已经有的**静态检查或项目自带检查。这些是正常工具使用，不是另搞一套扫描运行器。没有现成工具时，读代码即可，不要为跑本技能去安装工具或固定版本。

[可选规则](references/rules.yml) 是自包含的 semgrep 规则，供环境里已有 semgrep（或兼容工具）时当作线索来源；不是必跑项，命中也不定罪。

## 3. 核实

每条拟报告的发现都要对照证据 SHA 抽查，并同时满足下面的门槛后才能留下：

- **真实：** 文件在该 SHA 中存在，行号对得上，描述与代码一致。路径不存在、行号对不上、证据不足 → 丢弃。
- **在热路径上：** 能追到入口调用链（请求处理、遍历用户数据的循环、UI 渲染/列表、启动路径）。一次性脚本、迁移、测试、示例、生成代码或 vendor 中的命中 → 丢弃。
- **规模说得清：** 循环或结构遍历的是什么、多大（用户数据、分页上限、调用频率）。固定小 n → 丢弃。
- **代价说得清：** 能写出「何时触发 → 代价（多少次查询/拷贝/会阻塞什么）」。已有缓存、批量、分页或并发并且已经避开该代价的 → 丢弃或降级。
- **不编造测量：** 有测量就注明来源；只有复杂度或次数推断的必须标明「推断」并写出依据。既没有测量也说不清规模与代价 → 不进入正式发现，可列入低置信附录（最多 5 条），**不建 issue**。

词法、规则或 lint 命中只是线索。Compose / ArkTS / Swift 等框架特征更不是「一命中就报告」，必须有热路径、规模和代价证据。

完成：进入报告的每条都经过核实；被丢弃的有内部原因，不必向用户逐条解释。

## 4. 报告

交付中文报告，允许零发现。报告包含：

1. **范围**：仓库或路径、证据 SHA、本轮方向与方法；已使用的检查手段和未覆盖的方向（合理覆盖即可，不以找全为完成标准）。
2. **发现**：按严重级分组。每条写清：严重级、证据 SHA、文件路径与行号、问题、来源（规则/搜索/阅读）、触发条件、入口调用链、规模、代价（测量或推断，须标明）、建议修法、验收要点。
3. **低置信附录**（可选）：最多 5 条缺少完整证据的线索，不作为建单对象。
4. **未纳入**：仅在有必要时用一两句概括跳过的方向，不要把未核实的线索写成结论。

结论限定为「在所述范围和方法内发现或未发现」。严重级按已核实的真实影响评定，规则见 [扫描准则](references/criteria.md)，不要按模式名称自动定为最高级。

## 5. 可选建单与通知

仅当本轮用户明确授权把通过核实的发现写成 Fast Ship issue 时，才按 [建单规则](references/filing.md) 执行，查询与写入一律走 `$fast-ship`。未授权则停在报告，不要把「做了性能扫描」理解成已经允许建单。缺证据的条目不得建单。

若本轮确实新建了 issue：**只通知**项目名、编号与标题。没有新建则**静默**，不要发「扫了但没建单」的摘要。
